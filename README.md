# Website Accessibility Testing

## 📌 Project Overview

This is a Manual QA practice project focused on testing web accessibility and inclusive user experience.

The project demonstrates how a QA tester can verify whether a website is usable with different interaction methods and whether important accessibility requirements are properly supported.

## 🎯 Testing Objectives

- Verify keyboard accessibility
- Verify navigation using the Tab key
- Check visible focus indicators
- Verify form labels
- Check image alternative text
- Verify heading structure
- Check link accessibility
- Verify error messages
- Check text readability
- Identify basic accessibility issues
